# PDF tools from the reference workflow

The reference is a product workflow. ToolSite uses its own interface and original content. Each batch stays in development preview until its files, mobile layout and public page content pass review.

## Already supported

- Merge PDF, Split PDF, Compress PDF, PDF to JPG, and JPG to PDF
- Extract selected PDF pages through Split PDF using its existing extraction mode

## First expansion batch

- Rotate PDF, Remove PDF Pages, Add PDF Page Numbers, and Watermark PDF
- PDF to PowerPoint with one image per slide. Editable text reconstruction and OCR are separate milestones.

## Remaining tools

- Page operations: Organize PDF (reorder), Crop PDF, scan to PDF
- Document conversion: Word to PDF, PowerPoint to PDF, Excel to PDF, HTML to PDF, PDF to Word, PDF to Excel, PDF to PDF/A, PDF to Markdown
- Editing and forms: Edit PDF, PDF Forms
- Security and review: Protect PDF, remove encryption with the correct password, Sign PDF, Redact PDF, Compare PDF
- Recovery and recognition: Repair PDF, OCR PDF
- Document assistance: AI Summarizer and Translate PDF
- Workflows: chain compatible tools and save reusable recipes

Choose implementations against the browser-first and permissive-license requirements. Treat Office layout fidelity, searchable OCR, PDF/A validation, redaction verification, digital signatures and any external processing as explicit acceptance tests. Do not list unfinished features as available on the public directory.

Browser library added for PowerPoint: PptxGenJS 4.0.1 (MIT). The bundled JSZip component uses MIT. Keep the relevant notices in the library directory.
