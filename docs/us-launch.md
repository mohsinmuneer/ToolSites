# US launch priorities

These groups are prioritized by fit and readiness. Use US search performance to measure demand.

1. PDF workflows. Start with Merge PDF and JPG to PDF. Finish Split PDF and Compress PDF next.
2. School. Start with Grade Calculator and Word Counter. Finish GPA Calculator next.
3. Everyday math. Start with Percentage Calculator. Finish Tip Calculator, Discount Calculator and Days Until Calculator next.
4. Personal finance. Start with Loan Calculator. Finish Car Loan, Mortgage and Hourly to Salary next. Show assumptions, costs and exclusions clearly.

Set the production canonical origin in Seo:BaseUrl. Configure Seo:GoogleVerification and Seo:BingVerification with the token values from each service. Submit the sitemap and use the United States country filter in Search Console. Track each URL by query, impressions, clicks, average position and indexing status monthly.

Verify the owner, contact email, Privacy and Terms before submitting the production site for AdSense review. Use the approved publisher ID in Ads:PublisherId. Check /ads.txt before enabling ad slots.
